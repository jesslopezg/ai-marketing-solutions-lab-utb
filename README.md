# AI Marketing Solutions Lab · UTB–ETD

Guía interactiva de consulta para los tres grupos de Aplicaciones de Inteligencia Artificial al Marketing (2026-2).

- 20 actividades detalladas durante cuatro semanas.
- Cinco líneas de proyectos con ejemplos.
- Orientaciones para construir y probar un prototipo funcional de IA.
- Rúbrica de evaluación (40% del tercer corte).
- Entrega oficial exclusiva en Savio, el **23 de noviembre de 2026 a las 11:59 p. m., hora de Colombia**.

Para publicar, coloca `index.html` y `data.js` en la raíz y activa **Settings → Pages → Deploy from a branch → main / root**.

No almacena trabajos ni calificaciones. Diseño académico inspirado en UTB–ETD.
